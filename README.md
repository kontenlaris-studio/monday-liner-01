Worst Monday one-liner: my alarm didn't go off this morning — it quit too, because apparently even my alarm clock refuses to work on Mondays.

Why it works: the alarm clock is personified as a coworker who also quit on Monday — the dread is so universal even the machine that wakes you up refuses to participate. (109 characters, under the 140-character cap.)

## Run it

```sh
python3 main.py
```
